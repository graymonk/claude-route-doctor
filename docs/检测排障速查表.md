# 检测页排障速查表（一页纸版）

> 检测页：**https://ip.net.coffee/claude/** ｜ 详细说明见主教程第八部分
> 先记住：**只有两个"真泄露"**——DNS 显示中国运营商、UDP 出口显示国内真实 IP。其余黄标大多是噪声。

---

## ① 开关自检（每次排障第一步）

| 开关 | 应处状态 | 位置 |
|---|---|---|
| TUN 模式 | ✅ 开（堆栈 Mixed） | Clash Verge 设置页 / TUN 设置 |
| 系统代理 | ✅ 开 | Clash Verge 设置页 |
| Chrome 安全 DNS | ✅ Cloudflare (1.1.1.1) | chrome://settings/security |
| Clash IPv6 | ✅ 关 | 设置 → Clash 设置 |

**改过任何配置后：订阅页右键 →「使用」重新激活，再重测。**

---

## ② 检测页逐项判定

| 检测项 | 合格 | 不合格表现 → 跳转 |
|---|---|---|
| Claude AI 出口IP | = 你的住宅/专线节点 IP | 变机房 IP / 分数骤降 → ④ |
| 信任分 | 住宅 90+ 最佳；机房 50~75 可用 | 不可访问 / 滥用记录 → ⑥ |
| DNS 泄露 | 未检测到泄漏（海外服务商即可） | 显示中国DNS/电信 → ③ |
| WebRTC UDP | UDP 出口 = 海外节点 | 显示国内真实 IP → ⑤ |
| 时区 | 一致 | → 主教程 8.2（新加坡 IP 免做） |
| 语言 | 一致 | → 主教程 8.3 |
| IPv6 黄条 | 无 | → 主教程 8.4 |
| 中国出口 / Cloudflare 出口卡 | 显示什么都行 | 无需处理（Claude 看不到） |
| WebRTC「异常」标签 | 有也无需处理 | 出口不一致的假警告，非泄露（主教程 8.5） |

## ③ DNS 显示"中国DNS"（真泄露）

按顺序试，每步改完重新激活 + 重测：

1. TUN 设置 → 严格路由开 + 设置 → DNS 覆写开 → 重启 Clash 和浏览器
2. 确认 Chrome 安全 DNS = Cloudflare
3. **根治**：套用增强配置（本仓库 `references/merge-template.yaml`，即主教程附录A）→ 重新激活
   - 原因：Clash 默认上游是国内 DNS（223.5.5.5/119.29.29.29），陌生域名解析会带出运营商信息
   - 注意：DNS 出口显示香港/美国属于**正常**（任播），红线只有"中国DNS"

## ④ Claude 出口变机房 / 分数骤降（如 97→79）

本质：claude.ai 流量没走锁定节点。五步排查：

1. 三个开关是否全开（最常见：只开 TUN + Chrome 安全 DNS）
2. 「代理」页：Claude 用的组/节点是否被切到机房？是否在负载均衡组（必须退出）？
3. 嗅探配置（增强配置的 sniffer 段）是否已粘贴并重新激活？
4. 只开 TUN 时 ECH 必踩（Chrome 已移除关闭开关）→ 开系统代理即解
5. 改一处测一次，别一次改一堆

## ⑤ WebRTC UDP 显示国内真实 IP（真泄露）

1. 开 TUN（UDP 由它接管）——一般自动好
2. 仍漏：uBlock Origin → 设置 → 勾"防止 WebRTC 泄漏本地 IP"
3. 复查：https://browserleaks.com/webrtc 不能出现真实 IP

## ⑥ 信任分低 / 被标记

- 住宅 IP 90+ 是目标；机房 50~75 可用；「不可访问」必须换
- 机场：换一个住宅/AI 专线节点重测
- 自建：RackNerd 提工单付费换 IP；Vultr 销毁重建

## ⑦ 速度慢

- claude.ai 250~650ms = 住宅两跳正常水平，别追直连速度
- TUN 堆栈改 **Mixed**（gVisor 慢一大截）
- 换中转组节点实测延迟，挑最快的固定
- 红线：别为此切机房节点

---

## 最后防线（都试过还不行）

1. 重启 Clash Verge + 重启浏览器
2. 检查订阅是否过期 / 机场是否通报节点维护
3. 自建用户：服务器查 Xray 是否被升级（`/usr/local/bin/xray version`）、IP 是否被墙
4. 换一条线路重新注册前的环境检测必须重新做一遍
